About me #

Before we talk about pyinfra, I should introduce myself.

I worked at a Fortune 10 company for most of my career, where I did site reliability engineering for the reverse proxy behind a bunch of really big websites and over 2000 smaller ones, and where I built a data-lake-plus-feature-store for an ML organization.

In my spare time, I write about Python on this website, and I maintain the creatively named reader, a Python feed reader library and web app. Lately I've been working on a hosted version of reader, which is how I ended up using pyinfra.

What is pyinfra? #

pyinfra is a command-line tool that turns Python code into shell commands and runs them on your servers over SSH, in parallel. Think Ansible, but simpler.

deploy.py
for user in ['admin', 'alice', 'bob']:
    server.user(user)

files.put('files/hello.txt', '/etc/motd')

if host.data.get('install_postgres'):
    apt.install('postgresql')

Why use pyinfra? #

In short:

  • declarative and idempotent
  • infrastructure as actual code, not YAML
  • custom operations in 10 lines
  • works on any host you can SSH into
  • concurrent, "6× faster than Ansible"
  • scales to "thousands of servers"

I chose pyinfra over Ansible because it has most of the latter's good parts, most importantly that it is declarative – you describe what a server should look like, and pyinfra makes it so. Like Ansible, it's also imperative – if a server is already in the desired state, nothing happens when you run it again.

Unlike Ansible, there's no YAML – deploys (playbooks) are written in Python, which means you can do anything you can do in Python: you can have fors and ifs, you can have code completion and type checking, and can even import libraries.

Of interest to people using Ansible at larger scales, pyinfra is also faster. In my limited, small-scale experience, it was even faster than Ansible with the Mitogen plugin.

In fairness to Ansible, while pyinfra has been around for 10 years, it has fewer built-in operations (modules) and a smaller ecosystem, although that's partially offset by how simple it is.
